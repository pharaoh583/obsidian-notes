# 📥 Quick Capture

- **Rough Idea / Code Snippet:** 
	A Group is a set S equipped with an operation $*$, it should satisfy the following axioms:
	- It should have closure on the operation, that means $a, b \in S$ then  $a * b \in S$
	- It should be associative
	- It should have an operation neutral: $a*e = a$
	- It should have an inverse: $a*a^{-1} = e$

	An abelian group is a group that also satisfies commutativity
