- **Rough Idea / Code Snippet:** 
	Blockchain is a decentralized network that register some information, the information is inmutable and secure because is replicated through all the nodes in the network
	When adding a new node to the network there is a mechanism to check that the information is not manipulated, also, it rewards the the node that added the new block, some examples of this mechanisms are [[Proof of work]] and [[Proof of stake]]

	  - Decentralization
	  - Transparency
	  - Security
