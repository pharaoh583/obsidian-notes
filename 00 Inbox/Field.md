# 📥 Quick Capture

- **Rough Idea / Code Snippet:** 
	A Field is an [[Group|Abelian group]] that is also equipped with an additional operation $*$, it should satisfy the following axioms
	- It should have closure under the new operation: $a, b \in S$ then $a*b \in S$
	- It should be associative $a, b, c \in S$ then $a*(b*c) = (a*b)*c$
	- It should be commutative: $a*b = b*a$
	- It should be distributive: $a*(b+c) = a*b + a*c$
	- There should an neutral element or an identity: $a * I = a$ such that $I \in  S$
	- Each element should have an inverse: $a * a^{-1} = I$
