# 📥 Quick Capture

- **Rough Idea / Code Snippet:** 
  When we apply an space transformation to a vector through [[Matrices]] there are some vectors that only get scaled up and not moved. Those vectors are called eigenvectors and the scalar that each vector is scaled is the eigenvalue.
  If we use these vector as basis when getting the matrix of a transformation we obtain a diagonal matrix, where each element of the diagonal is one of the eigenvalues. When we can do this, we call the matrix diagonalizable 
  Not all matrices are diagonalizable.
