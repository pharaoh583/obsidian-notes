# 🧠 Feynman Summary

> [!summary] A field is an [[Group|Abelian group]] that support an additional way of combining the elements and all these combinations are reversible. 

## 📝 Core Concept

- **Context / Problem:** 
  A field $\mathbf{F}$ is an Abelian group $(G, +)$ that supports another operation $(\times)$. _Although the symbols $+, \times$ were used, they can represent other operations_.
	- It should have closure under the new operation: $a, b \in G$ then $a\times b \in G$
	- It should be associative $a, b, c \in S$ then $a\times(b\times c) = (a\times b)\times c$
	- It should be commutative: $a\times b = b\times a$
	- It should be distributive: $a\times(b+c) = a\times b + a\times c$ and $(b + c) \times a = b \times a + c \times a$
	- There should be a neutral element or an identity: $a ≠ 0$ and $a \times 1 = 1 \times a = a$ such that $1 \in  G$ (Where 1 $\in G$  represents an element that might be different from the actual number one and 0 is the neutral of the $+$ operation, it depends on the set)
	- Each element should have an inverse: $a \times a^{-1} = 1$
